# Calavi
#### Gestión de alquiler de habitaciones.

## Características
- Acceso solo para administradores
  ![Acceso](https://github.com/gasbis/calavi_habitaciones/blob/master/pantallas/acceso.png)
- Registro de los contratos de alquiler
- Señala si un contrato está próximo a caducar (un mes)
- Controla el cobro mensual
- Registro de gastos por capitulados
- Resumen global en págiina de inicio
